2. Hype AI Features — Token Budgets

Tonight AI Planner SHOWSTOPPER
User picks mood + group size + stops. System prompt includes 20-50 venue summaries from Supabase. Claude returns a structured evening itinerary with 3-5 stops, descriptions, and timing.
Input: ~2,500 tokens (system prompt + venue context + user preferences)
Output: ~1,200 tokens (structured plan with descriptions)
Calls per use: 1-2 (generate + optional regenerate)
AI City Pulse HIGH IMPACT
Home hero shows a dynamic, AI-written summary of what's happening in Sarajevo right now. Based on today's events, weather, time of day. Refreshes every few hours or on pull-to-refresh.
Input: ~1,500 tokens (today's events + weather + time context)
Output: ~200 tokens (2-3 sentence blurb)
Calls per use: 1 (cached for several hours)
Natural Language Search
"Good coffee near Baščaršija" → structured search filters. Interprets intent, maps to categories/neighborhoods/moods, returns Supabase query parameters.
Input: ~800 tokens (system prompt + user query + available filters)
Output: ~150 tokens (structured JSON filters)
Calls per use: 1 per search
Venue/Event Descriptions
Enrich thin database descriptions with engaging, tourism-ready copy. Batch job, not real-time. Run offline, store results.
Input: ~500 tokens (venue data + style prompt)
Output: ~300 tokens (description)
Calls per use: Batch — one-time per entity

Recommended Strategy: Multi-Provider Mix

Don't lock into one provider. Use the best model for each feature based on quality needs and cost:

FeatureRecommended ModelWhy
Tonight AI Planner GPT-4.1 mini Best instruction-following for structured itineraries. Strong creative output. $0.007/plan.
City Pulse (Home hero) Gemini 2.5 Flash-Lite Cached result shared across all users. Cheapest option works fine. Near-free at scale.
NL Search GPT-4.1 nano Structured JSON output from short queries. Fastest, cheapest option that's reliable.
Batch Descriptions Claude Haiku 4.5 Best prose voice for tourism copy. One-time batch cost, not per-session. Use batch API for 50% off.

Blended session cost with this mix: ~$0.004/session ($4/1K sessions, $120/month at 1K users)

For the presentation demo: Use Gemini 2.5 Flash free tier for everything — zero cost, 250 requests/day is more than enough for a demo. Swap to the optimized mix when real users arrive.

Key insight for the tourism board: AI features cost pennies per user. At 1,000 monthly active users, the entire AI layer costs less than a single coffee in Sarajevo per day. This is not a cost problem — it's a capability unlock. The board should focus on what it enables (personalized discovery, intelligent recommendations, dynamic content) not what it costs.
